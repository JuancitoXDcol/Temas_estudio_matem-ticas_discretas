Aritmética modular, primos, RSA y teoría de códigos para detección de errores.

1. Cifrado RSA Básico

Explicación Matemática

RSA se basa en la dificultad computacional de la factorización de enteros grandes y las propiedades del **Teorema de Euler** ($a^{\phi(n)} \equiv 1 \pmod n$).

  1. Seleccionar primos grandes $p$ y $q$. Calcular $n = p \cdot q$ y la función Phi de Euler $\phi(n) = (p-1)(q-1)$.
  2. Elegir clave pública $e$ tal que $1 < e < \phi(n)$ y $\gcd(e, \phi(n)) = 1$.
  3. Calcular clave privada $d \equiv e^{-1} \pmod{\phi(n)}$ mediante el **Algoritmo Extendido de Euclides** ($e \cdot d \equiv 1 \pmod{\phi(n)}$).
  4. Cifrado: $C = M^e \pmod n$. Descifrado: $M = C^d \pmod n$.

Ejemplo Aplicado

Generación de claves simples con $p = 61$ y $q = 53$:

$n = 61 \times 53 = 3233$, $\phi(n) = (60)(52) = 3120$.

Elegimos $e = 17$ (ya que $\gcd(17, 3120) = 1$). Calculando el inverso inverso modular $d$: $17 \cdot d \equiv 1 \pmod{3120} \implies d = 2753$.

Para cifrar el mensaje $M = 65$:

$C = 65^{17} \pmod{3233} = 2790$.

Para descifrar: $M = 2790^{2753} \pmod{3233} = 65$.

Ejercicios de Práctica

2. Códigos de Detección y Corrección de Errores (Hamming)

Explicación Matemática

Los códigos de bloque lineales agregan redundancia mediante bits de paridad. La **Distancia de Hamming** $d_H(x, y)$ es el número de posiciones en las que dos vectores de bits difieren.

  • Para detectar hasta $k$ errores, se requiere una distancia mínima $d_{\min} \ge k + 1$.
  • Para corregir hasta $t$ errores, se requiere una distancia mínima $d_{\min} \ge 2t + 1$.
  • Código de Hamming (7,4): Utiliza 4 bits de datos y 3 bits de paridad ubicados en posiciones potencias de 2 ($1, 2, 4$). Permite corregir errores de $1$ bit ($t=1$) ya que $d_{\min} = 3$.

Ejemplo Aplicado

Transmisión del dato $D = 1011$ con Hamming (7,4):

Posiciones de bits: $P_1, P_2, D_3, P_4, D_5, D_6, D_7$. Colocando datos: $\underline{\text{ }} \; \underline{\text{ }} \; 1 \; \underline{\text{ }} \; 0 \; 1 \; 1$.

  • $P_1$ (cubre pos 1,3,5,7): $P_1 \oplus 1 \oplus 0 \oplus 1 = 0 \implies P_1 = 0$.
  • $P_2$ (cubre pos 2,3,6,7): $P_2 \oplus 1 \oplus 1 \oplus 1 = 0 \implies P_2 = 1$.
  • $P_4$ (cubre pos 4,5,6,7): $P_4 \oplus 0 \oplus 1 \oplus 1 = 0 \implies P_4 = 0$.

Vector transmitido: 0 1 1 0 0 1 1.

Ejercicios de Práctica

Ejercicio 2.2: Si un esquema de codificación tiene una distancia mínima $d_{\min} = 5$, ¿cuántos errores de bits por palabra puede CORREGIR garantizadamente?
